# Login Attempt Analyzer (C)

This program reads login attempts from a file and analyzes them.

## Features
- counts total login attempts
- detects successful logins
- detects failed logins
- displays statistics

## Concepts used
- file handling
- strings
- loops
- conditions

## Input file
Create a file named `logins.txt` with username and password on each line.

## Compilation
gcc login.c -o login

## Execution
./logins
